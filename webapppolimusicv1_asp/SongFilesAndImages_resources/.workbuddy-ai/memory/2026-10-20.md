# 2026-10-20

## App web PoliMusic (ASP Clásico + SQL Server) — construida desde cero

Se creó la aplicación completa en `webapppolimusicv1_asp/` a partir del script
`BDD_PoliMusic (1).sql` (que estaba en UTF-16 y hubo que decodificar para leer el esquema).

**Archivos creados**

| Archivo | Rol |
|---|---|
| `conexion.asp` | Config BD, `AbrirConexion`/`CerrarConexion` con 3 cadenas en fallback, `Esc`, `BaseUrl`, `RutaRecurso`, `UrlRecurso`, `UrlImagen`, `DecodificarXml`, `RutaConArchivo`, `ListarAudio`, `NuevoComando`/`AgregarParam`, flash messages |
| `seguridad.asp` | `RequiereSesion`, `RequiereAdmin`, `EsAdmin`, `EtiquetaRol`, `IniciarSesion`, `DestruirSesion` |
| `header.asp` / `footer.asp` | Layout: navbar con avatar, badge de rol y logout; cierre de conexión |
| `login.asp` | Login con consulta parametrizada que acepta contraseña en texto plano **y** MD5 (`HASHBYTES`) |
| `logout.asp` | `RemoveAll` + `Abandon` + limpieza de cookie |
| `canciones.asp` | Listado con JOINs N:M vía `STUFF/FOR XML PATH`, búsqueda, paginación (OFFSET/FETCH), modal CRUD, reproductor fijo |
| `cancion_accion.asp` | POST transaccional insertar/actualizar/eliminar (limpia `TBL_PLAYER`, `TBL_TRACKLIST` y `TBL_PLAYLIST_SONG` antes de borrar la canción) |
| `api_play.asp` | AJAX: `UPDATE ... OUTPUT INSERTED.PLAYS`, devuelve JSON |
| `css/estilos.css` | Tema oscuro violeta/cian, ~300 reglas, responsive |
| `js/app.js` | Reproductor global, modal, confirmaciones, toggle de contraseña |
| `README.md` | Instalación en IIS, credenciales, decisiones técnicas y troubleshooting |

**Hallazgos del esquema que condicionaron el código**
- `SONG_PATH` guarda `~/songFiles/...` (minúsculas) pero la carpeta real es `SongFiles/`.
- Las carpetas `AlbumImages/` y `ArtistImages/` **no existen** → `UrlImagen()` valida con FSO y cae a `PlaylistImages/default.jpg`.
- `TBL_PLAYLIST_SONG` también tiene FK a `TBL_SONG`: el borrado debe limpiarla o falla.
- `TBL_USER` mezcla contraseñas planas (`12345678`) y un MD5 (`username1`).
- Sólo existe `bensound-adventure.mp3`; las otras 4 pistas de la BD darán 404 (el player muestra aviso).
